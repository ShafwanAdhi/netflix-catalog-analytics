# Project capabilities

Analyze the calendar-year difference between original release and catalog entry. Compare metadata-based regression models and inspect scoped historical insights. The target is not a measure of commercial success, popularity or exact elapsed time.

| Capability | Implementation and evidence |
| --- | --- |
| Advanced feature engineering | Base/advanced encoders, log/count/missingness/interactions; exclusion and vocabulary tests |
| Multiple ML models | Median baselines, Ridge/forest; 18 specifications and persisted CV |
| Compare performance | Chronological CV, frozen selection, test/baseline/cohort results |
| Automated insights | Deterministic supported comparisons, references, quality and permutation diagnostics |
| Visual reports | Five sections, charts, report figures, executed notebook |

The web application has five sections: `/overview`, `/dataset`, `/insights`, `/evaluation` and `/methodology`. All displayed model results come from a validated saved run. Inspect [methodology](methodology.md), [model card](model-card.md) and [verification](../VERIFICATION.md) for practical limits and recorded checks.
